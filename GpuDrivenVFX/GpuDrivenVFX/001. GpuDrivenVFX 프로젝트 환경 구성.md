# 주요 내용

## ⚙️ 프로젝트 설정

### Configuration Properties

- `Configuration`: `All Configurations` / `Platform`: `x64`
- `Character Set`: `Use Unicode Character Set`
- `C++ Language Standard`: `ISO C++17 Standard (/std:c++17)`

### Precompiled Header
- `Precompiled Header` → `Use (/Yu)`
- `Precompiled Header` → `Create (/Yc)` (`pch.cpp`)

### Linker
- `Additional Dependencies`: `d3d11.lib`, `dxgi.lib`, `d3dcompiler.lib` 추가 
- `Subsystem`: `Windows (/SUBSYSTEM:WINDOWS)`

## 💻 코드

**pch.h**

```C
#pragma once

//------------------------------------------------------------------------
// WinAPI 헤더
//------------------------------------------------------------------------
#define WIN32_LEAN_AND_MEAN		// <window.h>에서 불필요한 Windows API 생략 
#define NOMINMAX				// <windows.h>이 min, max 매크로를 정의하지 않음

#include <windows.h>

//------------------------------------------------------------------------
// DirectX 11 관련 헤더
//------------------------------------------------------------------------
#include <d3d11.h>				// DirectX 11 핵심 API
#include <dxgi.h>				// SwapChain, Adapter, Display 관련 API
#include <d3dcompiler.h>		// HLSL Shader 컴파일 API
#include <DirectXMath.h>		// Vector, Matrix 계산용 수학 라이브러리

//------------------------------------------------------------------------
// ComPtr 헤더
//------------------------------------------------------------------------
#include <wrl/client.h>

//------------------------------------------------------------------------
// C++ 표준 라이브러리
//------------------------------------------------------------------------
#include <cstdint>				// 고정 크기 정수 자료형 제공
#include <memory>				// 스마트 포인터 제공
#include <string>				// 문자열 클래스 제공
#include <vector>				// 동적 크기 배열 컨테이너 제공
#include <array>				// 고정 크기 배열 컨테이너 제공
#include <chrono>				// 시간 측정 도구 제공
#include <cassert>				// 조건 검증 기능 제공
#include <stdexcept>			// 표준 예외 클래스 제공
```

자주 사용할 헤더들을 `Precompiled Header`로 미리 작성하였습니다.
