# 일일 목표

- [x] GPU Particle에 대한 간접 드로우 파이프라인 구조 완성

***
# 주요 내용

기존 `DrawIndexedInstanced` 함수 기반의 드로우 방식을 `DrawIndexedInstancedIndirect` 함수 기반으로 변경하여, **Vertex Shader가 활성 상태인 Particle에 대해서만 정점 연산을 수행할 수 있도록 구조를 개선**하였습니다.

## 💻 코드

**rendering/gpu_billboard_renderer.h**

```C
class GpuBillboardRenderer
{
...

private:
	// DrawIndexedInstancedIndirect 호출에 사용할 argument buffer
    Microsoft::WRL::ComPtr<ID3D11Buffer> m_indirectArgsBuffer;
	
    // Compute Shader에서 indirect argument buffer를 쓰기 위한 UAV
    Microsoft::WRL::ComPtr<ID3D11UnorderedAccessView> m_indirectArgsUav;
	
    // indirect argument buffer를 갱신하는 Compute Shader
    Microsoft::WRL::ComPtr<ID3D11ComputeShader> m_indirectArgsComputeShader;
    
    ...
}
```

`DrawIndexedInstancedIndirect` 함수는 **`ID3D11Buffer`와 오프셋을 인자로 받아, 버퍼 내부에 정렬된 데이터를 GPU가 직접 파싱하여 드로우 콜을 구동하는 형식**입니다.

이에 따라 **버퍼 객체와 UAV를 클래스 멤버 변수로 추가**하여 `GpuBillboardRenderer` 클래스 내부에서 버퍼 구성 및 갱신 작업을 수행할 수 있도록 하였으며, **간접 인자 버퍼의 데이터를 조립하기 위한 Compute Shader 객체도 함께 추가**하였습니다.

```C
class GpuBillboardRenderer
{
...

private:
	// DrawIndexedInstancedIndirect에 사용할 argument buffer를 생성하는 함수
    bool CreateIndirectArgsBuffer(ID3D11Device* device);
	
    // Indirect draw argument buffer를 갱신할 Compute Shader를 생성하는 함수
    bool CreateIndirectArgsComputeShader(ID3D11Device* device);
	
    ...
	
    // 현재 활성 Particle 개수를 기반으로 indirect argument buffer를 갱신하는 함수
    void UpdateIndirectArgsBuffer
    (
	    ID3D11DeviceContext* context,
	    ID3D11ShaderResourceView* aliveCountSrv
	);
	 
    ...
}
```

**간접 인자 버퍼를 생성**하는 함수(`CreateIndirectArgsBuffer`)와 **해당 버퍼를 갱신할 Compute Shader를 생성**하는 함수(`CreateIndirectArgsComputeShader`) 선언을 추가하였습니다.

**현재 프레임에서의 Active Particle 개수를 기반으로 간접 인자 버퍼를 갱신**하는 함수도 추가하였습니다. (`UpdateIndirectArgsBuffer`)

```C
class GpuBillboardRenderer
{
public:
	...
	
	// GPU Particle Buffer를 읽어 Billboard Quad를 렌더링하는 함수
    void Render
    (
        ID3D11DeviceContext* context,
        const Camera& camera,
        ID3D11ShaderResourceView* particleSrv,
        ID3D11ShaderResourceView* aliveIndexSrv,
        ID3D11ShaderResourceView* aliveCountSrv
    );
}
```

`Render` 함수에서는 더 이상 `particleCount`를 Draw Call에 직접 사용하지 않으므로, 함수 시그니처를 변경하였습니다.


**rendering/gpu_billboard_renderer.cpp**

```C
bool GpuBillboardRenderer::Initialize(ID3D11Device* device)
{
    ...
	
    // Indirect Draw argument buffer 생성
    if (!CreateIndirectArgsBuffer(device))
    {
        // 생성하지 못한 경우 실패 처리
        return false;
    }
	
    // Indirect Draw argument buffer 갱신용 Compute Shader 생성
    if (!CreateIndirectArgsComputeShader(device))
    {
        // 생성하지 못한 경우 실패 처리
        return false;
    }
	
    return true;
}
```

`Initialize` 함수에 **간접 인자 버퍼**와 **해당 버퍼를 갱신하기 위한 Compute Shader**를 생성하는 코드를 추가하였습니다.

```C

bool GpuBillboardRenderer::CreateIndirectArgsBuffer(ID3D11Device* device)
{
    ...
	
    // DrawIndexedInstancedIndirect argument 초기 값
    // [0] IndexCountPerInstance = 6
    // [1] InstanceCount = 0
    // [2] StartIndexLocation = 0
    // [3] BaseVertexLocation = 0
    // [4] StartInstanceLocation = 0
    const UINT initialArgs[5] =
    {
        6,
        0,
        0,
        0,
        0
    };
	
    D3D11_BUFFER_DESC bufferDesc = {};
    bufferDesc.ByteWidth = sizeof(initialArgs);
    bufferDesc.Usage = D3D11_USAGE_DEFAULT;
    bufferDesc.BindFlags = D3D11_BIND_UNORDERED_ACCESS;
    bufferDesc.CPUAccessFlags = 0;
    bufferDesc.MiscFlags =
	    D3D11_RESOURCE_MISC_DRAWINDIRECT_ARGS |
	    D3D11_RESOURCE_MISC_BUFFER_ALLOW_RAW_VIEWS;
    bufferDesc.StructureByteStride = 0;
	
    D3D11_SUBRESOURCE_DATA initialData = {};
    initialData.pSysMem = initialArgs;
	
    HRESULT hr = device->CreateBuffer
    (
        &bufferDesc,
        &initialData,
        m_indirectArgsBuffer.GetAddressOf()
    );
	
    ...
	
    D3D11_UNORDERED_ACCESS_VIEW_DESC uavDesc = {};
    uavDesc.Format = DXGI_FORMAT_R32_TYPELESS;
    uavDesc.ViewDimension = D3D11_UAV_DIMENSION_BUFFER;
    uavDesc.Buffer.FirstElement = 0;
    uavDesc.Buffer.NumElements = ARRAYSIZE(initialArgs);
    uavDesc.Buffer.Flags = D3D11_BUFFER_UAV_FLAG_RAW;
	
    hr = device->CreateUnorderedAccessView
    (
        m_indirectArgsBuffer.Get(),
        &uavDesc,
        m_indirectArgsUav.GetAddressOf()
    );
	
    ...
	
    return true;
}
```

`CreateIndirectArgsBuffer` 함수의 주요 작동 로직은 다음과 같습니다.

- **간접 드로우 명령 인자 초기화**
  인스턴스를 드로우할 때 인덱스 버퍼에서 읽어야 하는 인덱스 개수(`IndexCountPerInstance`)는 6으로 설정하고, 나머지 인자들은 모두 0으로 설정하였습니다.

- **간접 인자 버퍼 생성**
  `CreateBuffer` 함수를 통해 간접 인자 버퍼를 생성하였습니다.
  이 과정에서 `MiscFlags`의 `D3D11_RESOURCE_MISC_DRAWINDIRECT_ARGS`에  `D3D11_RESOURCE_MISC_BUFFER_ALLOW_RAW_VIEWS`를 조합하여, Compute Shader에서 간접 인자 버퍼에 **바이트 오프셋 단위로 주소를 직접 지정하여 기록할 수 있도록 설정**하였습니다.

- **Comput Shader 접근용 UAV 생성**
  `CreateUnorderedAccessView` 함수를 통해 UAV를 생성하였습니다.
  `Format`을 `DXGI_FORMAT_R32_TYPELESS`으로 설정하여 **4바이트 단위로 메모리 주소에 직접 접근하여 데이터를 기록할 수 있도록 설정**하였습니다.
  또한 `Buffer.Flags`를 `D3D11_BUFFER_UAV_FLAG_RAW`로 설정하여 **UAV가 가리키는 대상이 바이트 주소 버퍼 구조라는 것을 명시**하였습니다.

```C
void GpuBillboardRenderer::UpdateIndirectArgsBuffer
(
	ID3D11DeviceContext* context,
	ID3D11ShaderResourceView* aliveCountSrv
)
{
    ...
    
    // indirect argument 갱신용 Compute Shader 바인딩
    context->CSSetShader(m_indirectArgsComputeShader.Get(), nullptr, 0);
	
    // active Particle 개수 SRV를 Compute Shader에 바인딩
    ID3D11ShaderResourceView* shaderResourceViews[] =
    {
        aliveCountSrv
    };
	
    context->CSSetShaderResources
    (
        0,
        1,
        shaderResourceViews
    );
	
    // indirect argument buffer UAV 바인딩
    ID3D11UnorderedAccessView* unorderedAccessViews[] =
    {
        m_indirectArgsUav.Get()
    };
	
    context->CSSetUnorderedAccessViews
    (
        0,
        1,
        unorderedAccessViews,
        nullptr
    );
	
    // draw argument는 하나만 작성하면 되므로 thread group 1개만 실행
    context->Dispatch(1, 1, 1);
	
    // 이후 DrawIndexedInstancedIndirect에서
    // Indirect Argument Buffer를 읽을 수 있도록 UAV 바인딩 해제
    ID3D11UnorderedAccessView* nullUnorderedAccessViews[] = { nullptr };
	
    context->CSSetUnorderedAccessViews
    (
        0,
        1,
        nullUnorderedAccessViews,
        nullptr
    );
	
    // 다음 프레임 aliveCount UAV 사용과 충돌하지 않도록 SRV 바인딩 해제
    ID3D11ShaderResourceView* nullShaderResourceViews[] = { nullptr };
	
    context->CSSetShaderResources
    (
        0,
        1,
        nullShaderResourceViews
    );
	
    // Compute Shader 바인딩 해제
    context->CSSetShader(nullptr, nullptr, 0);
}
```

`UpdateIndirectArgsBuffer`에서는 **간접 인자 버퍼에 대한 갱신 작업을 수행**합니다.

이 과정에서 버퍼 갱신용 Compute Shader에 **활성 Particle 개수 SRV**와 **간접 인자 버퍼 UAV**를 셰이더 레지스터에 바인딩합니다.

바인딩 이후에는 버퍼를 한 번만 조립하면 되므로 **`Dispatch(1, 1, 1)`을 호출하여 최소한의 스레드 그룹만 구동**하도록 구현하였습니다.

연산 후에는 **바인딩한 SRV/UAV 해제 작업을 수행**하여 후속 그래픽스 단계에서의 리소스 해저드를 방지하였습니다.

```C
void GpuBillboardRenderer::Render
(
    ID3D11DeviceContext* context,
    const Camera& camera,
    ID3D11ShaderResourceView* particleSrv,
    ID3D11ShaderResourceView* aliveIndexSrv,
    ID3D11ShaderResourceView* aliveCountSrv
)
{
    ...
    
    // 현재 active Particle 개수를 기반으로 indirect draw argument buffer 갱신
    UpdateIndirectArgsBuffer(context, aliveCountSrv);
	
    // GPU Billboard 셰이더 바인딩
    m_shader.Bind(context);
	
    // 현재 프레임에서 사용할 카메라 변환 행렬을 정점 셰이더에 전달
    UpdateCameraBuffer(context, camera);
	
    // GPU Particle Buffer, alive index list를 정점 셰이더에 바인딩
    ID3D11ShaderResourceView* shaderResourceViews[] =
    {
        particleSrv,
        aliveIndexSrv,
    };
	
    context->VSSetShaderResources
    (
        0,
        2,
        shaderResourceViews
    );
	
    ...
    
    // GPU Particle Buffer의 각 Particle 슬롯을 하나의 Billboard 인스턴스로 렌더링
    context->DrawIndexedInstancedIndirect
    (
        m_indirectArgsBuffer.Get(),
        0
    );
	
    // 다음 Compute Shader 업데이트에서 버퍼를 사용할 수 있도록 SRV 바인딩 해제
    ID3D11ShaderResourceView* nullShaderResourceViews[] =
    {
        nullptr,
        nullptr
    };
	
    context->VSSetShaderResources
    (
        0,
        2,
        nullShaderResourceViews
    );
}
```

`Render` 함수에서 렌더링 작업 수행 전 `UpdateIndirectArgsBuffer` 함수를 호출하여 **현재 프레임의 간접 인자 버퍼를 갱신하도록 설정**하였습니다.

이번 작업 이후에는 정점 셰이더가 `aliveCount`에 접근할 필요가 없으므로, **Alive Count SRV는 바인딩하지 않도록 수정**하였습니다.

필요한 리소스를 바인딩한 후에는 `DrawIndexedInstancedIndirect` 함수 호출을 통해 **활성 상태인 Particle에 한정된 드로우 콜을 수행**하도록 변경하였습니다.


**shaders/GpuBillboardDrawArgsComputeShader.hlsl**

```HLSL
// 현재 프레임의 active Particle 개수
StructuredBuffer<uint> aliveCount : register(t0);

// DrawIndexedInstancedIndirect가 사용할 argument buffer
RWByteAddressBuffer drawArgs : register(u0);

// DrawIndexedInstancedIndirect argument layout:
// Byte offset 00 : IndexCountPerInstance
// Byte offset 04 : InstanceCount
// Byte offset 08 : StartIndexLocation
// Byte offset 12 : BaseVertexLocation
// Byte offset 16 : StartInstanceLocation
[numthreads(1, 1, 1)]
void CS_Main(uint3 dispatchThreadId : SV_DispatchThreadID)
{
    // Billboard Quad는 인덱스 6개로 구성
    drawArgs.Store(0, 6);
	
    // Compute Shader에서 계산한 active Particle 개수를 instance count로 사용
    drawArgs.Store(4, aliveCount[0]);
	
    // Index Buffer 시작 위치
    drawArgs.Store(8, 0);
	
    // Base Vertex Location
    drawArgs.Store(12, 0);
	
    // Start Instance Location
    drawArgs.Store(16, 0);
}
```

**간접 인자 버퍼 갱신을 위한 Compute Shader 코드**입니다.

`UpdateIndirectArgsBuffer` 함수에서 바인딩한 **Alive Particle SRV를 기반으로 간접 인자 버퍼 UAV에 쓰기 작업을 수행**합니다.

이 때 `DrawIndexedInstancedIndirect`에서 요구하는 규격과 일치하도록, 다음과 같이 **4바이트 단위 바이트 오프셋 지정 방식으로 데이터를 조립**합니다.

- `00-03` : `IndexCountPerInstance` → **Quad 인덱스 개수인 6으로 고정**
- `04-07` : `InstanceCount` → **Compute Shader에서 계산한 active Particle 개수**를 대입
- `08-11` : `StartIndexLocation` → 0으로 고정
- `12-15` : `BaseVertexLocation` → 0으로 고정
- `16-19` : `StartInstanceLocation` → 0으로 고정


**shaders/GpuBillboardVertexShader.hlsl**

```HLSL
// GPU Particle Buffer를 정점 셰이더에서 읽기 위한 Structured Buffer
StructuredBuffer<GpuParticleData> particles : register(t0);

// active Particle의 원본 Particle 인덱스 목록
StructuredBuffer<uint> aliveIndices : register(t1);

...

// 각 GPU Billboard 정점마다 실행되는 정점 셰이더의 Entry Point
VSOutput VS_Main(VSInput input, uint instanceId : SV_InstanceID)
{
    VSOutput output;
    
    // 현재 인스턴스에 대응하는 active Particle의 원본 Particle 인덱스 조회
    uint particleIndex = aliveIndices[instanceId];
	
    // active Particle 인덱스를 통해 GPU Particle 데이터 조회
    GpuParticleData particle = particles[particleIndex];
	
    ...
	
    return output;
}
```

기존에는 정점 셰이더에 `aliveCount` SRV를 바인딩하여, `SV_InstanceID`가 활성 Particle 개수를 초과할 경우 정점의 위치나 면적을 0으로 축소하는 예외 처리 분기문을 수행하였습니다.
이로 인해 비활성 상태의 Particle도 셰이더 스레드를 점유하게 되어 불필요한 정점 연산을 수행하게 되는 문제가 발생하였습니다.

`DrawIndexedInstancedIndirect` 함수를 활용한 **간접 드로우 파이프라인 구조에서는 활성 상태인 Particle 인스턴스만 선별되어 정점 셰이더로 전달**됩니다.
이에 따라 셰이더 내 불필요한 예외 처리 분기문과 관련 리소스 바인딩을 제거하고, **유효한 정점 연산만 수행하도록 구조를 개선**하였습니다.
