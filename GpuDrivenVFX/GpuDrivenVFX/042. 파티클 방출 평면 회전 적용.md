**방출 평면의 회전 각도를 갱신**하는 함수(`UpdateEmitterPlaneRotation`)를 선언하였습니다.


**particle/cpu_particle_system.cpp**

```C
void CpuParticleSystem::Update(float deltaTime)
{
    // Spiral Particle 방출 평면의 회전 각도 갱신
    UpdateEmitterPlaneRotation(deltaTime);
	
    // 활성 상태의 Particle 수명 및 위치 갱신  
	UpdateParticles(deltaTime);
	
	...
}
```

`Update` 단계에서 `UpdateEmitterPlaneRotation` 함수를 호출하여 **Emitter가 사용하는 Spiral 방출 평면의 현재 회전 각도를 갱신**하였습니다.  
  
이후 `UpdateParticles` 함수에서 **갱신된 회전 각도를 포함한 회전 행렬을 고려**하여 각 파티클의 로컬 위치를 월드 공간 위치로 변환합니다.

```C
void CpuParticleSystem::UpdateParticles(float deltaTime)
{
    // 중심 방출형 Particle의 회전 반경 설정
    const float pitch = ParticleConfig::SpiralPitch;
    const float yaw = ParticleConfig::SpiralYaw;
	
    // 기본 기울기와 시간 기반 평면 회전을 조합한 회전 행렬 생성
    DirectX::XMMATRIX rotationMatrix =
	    DirectX::XMMatrixRotationRollPitchYaw
		(
		    pitch,
		    yaw,
		    m_emitter.planeRotationAngle
		);
	
	...
	
}
```

`UpdateParticles` 함수에서 `ParticleConfig`에 정의된 `SpiralPitch`, `SpiralYaw` 값과 **매 프레임 갱신되는 `planeRotationAngle` 값을 조합**하여 중심 방출형 파티클의 회전 행렬을 생성하도록 수정하였습니다.

_planeRotationAngle을 Roll 회전값으로 적용해, 방출 평면이 시간에 따라 회전하는 효과를 구현_


```C
void CpuParticleSystem::UpdateEmitterPlaneRotation(float deltaTime)
{
    // Spiral Particle 방출 평면을 시간에 따라 회전
    m_emitter.planeRotationAngle +=
	    ParticleConfig::SpiralPlaneRotationSpeed * deltaTime;
	
    // 각도가 너무 커지는 것을 방지
    if (m_emitter.planeRotationAngle > DirectX::XM_2PI)
    {
        m_emitter.planeRotationAngle -= DirectX::XM_2PI;
    }
}
```

**방출 평면의 회전 각도를 갱신**하는 함수를 정의하였습니다.

Emitter의 `planeRotationAngle` 값을 `deltaTime` 기반으로 누적 갱신하여 **프레임 속도와 무관하게 일정한 속도로 방출 평면이 회전**하도록 하였습니다.

또한 각도가 2π를 초과하면 다시 2π만큼 뺌으로써 **회전 각도가 불필요하게 계속 커지는 것을 방지**하였습니다.

`ParticleEmitter` 구조체에 `planeRotationAngle` 변수를 추가하여, **시간에 따라 회전하는 방출 평면의 현재 각도를 Emitter 상태로 관리**하도록 설정하였습니다.

`deltaTime` 기반으로 **Emitter의 `planeRotationAngle` 속성을 갱신**하는 함수를 추가하였습니다.

**particle/gpu_particle_system.cpp**

```C
void GpuParticleSystem::CalculateSpiralBasis(float planeRotationAngle)
{
    // 중심 방출형 파티클에 적용할 회전 행렬
    const DirectX::XMMATRIX spiralRotationMatrix =
        DirectX::XMMatrixRotationRollPitchYaw
        (
            ParticleConfig::SpiralPitch,
            ParticleConfig::SpiralYaw,
            planeRotationAngle
        );
	
    // 회전 행렬의 첫 번째 행 추출(회전 후 기저의 X축 방향)
    const DirectX::XMVECTOR spiralRight =
	    DirectX::XMVectorSetW(spiralRotationMatrix.r[0], 0.0f);
    // 회전 행렬의 첫 번째 행 추출(회전 후 기저의 Y축 방향)
    const DirectX::XMVECTOR spiralUp =
	    DirectX::XMVectorSetW(spiralRotationMatrix.r[1], 0.0f);
    // 회전 행렬의 첫 번째 행 추출(회전 후 기저의 Z축 방향)
    const DirectX::XMVECTOR spiralForward =
	    DirectX::XMVectorSetW(spiralRotationMatrix.r[2], 0.0f);
	
    DirectX::XMStoreFloat4(&m_spiralRight, spiralRight);
    DirectX::XMStoreFloat4(&m_spiralUp, spiralUp);
    DirectX::XMStoreFloat4(&m_spiralForward, spiralForward);
}
```

`CalculateSpiralBasis` 함수에서 인자로 받은 `planeRotationAngle`를 **회전 행렬의 Row 회전값으로 적용**하여 방출 평면이 시간에 따라 회전할 수 있도록 설정하였습니다.

```C
void GpuParticleSystem::UpdateEmitterPlaneRotation(float deltaTime)
{
    // Spiral Particle 방출 평면을 시간에 따라 회전
    m_emitter.planeRotationAngle +=
        ParticleConfig::SpiralPlaneRotationSpeed * deltaTime;
	
    // 각도가 너무 커지는 것을 방지
    if (m_emitter.planeRotationAngle > DirectX::XM_2PI)
    {
        m_emitter.planeRotationAngle -= DirectX::XM_2PI;
    }
}
```

방출 평면의 회전 각도를 갱신**하는 함수를 정의하였습니다.

Emitter의 `planeRotationAngle` 값을 `deltaTime` 기반으로 누적 갱신하여 **프레임 속도와 무관하게 일정한 속도로 방출 평면이 회전**하도록 하였습니다.

또한 각도가 2π를 초과하면 다시 2π만큼 뺌으로써 **회전 각도가 불필요하게 계속 커지는 것을 방지**하였습니다.

```C
void GpuParticleSystem::Update(ID3D11DeviceContext* context, float deltaTime)
{
    ...
    
    // Emitter의 방출 평면 회전 각도 갱신
    UpdateEmitterPlaneRotation(deltaTime);
	
    // 갱신된 회전 각도를 기준으로 Spiral basis 벡터 재계산
    CalculateSpiralBasis(m_emitter.planeRotationAngle);
	
    ...
}
```

`Update` 단계에서 `UpdateEmitterPlaneRotation` 함수를 호출하여 **Emitter의 방출 평면 회전 각도를 갱신**하고, 갱신된 `planeRotationAngle` 값을 기반으로 Spiral basis 벡터를 다시 계산하도록 설정하였습니다.

이렇게 계산된 basis 벡터는 **파티클 갱신 상수 버퍼를 통해 Compute Shader로 전달**되며, 파티클 위치 계산에 활용됩니다.
