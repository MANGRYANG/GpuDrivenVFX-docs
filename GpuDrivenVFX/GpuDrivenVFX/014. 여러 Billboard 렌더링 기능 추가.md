# 일일 목표

- [x] 기존의 단일 Billboard 렌더링 구조를 다수의 Billboard를 렌더링할 수 있도록 변경

# 주요 내용

## 💻 코드

**billboard_renderer.h**

```C
// Billboard Quad 정보 구조체
struct Billboard
{
    // Billboard Quad의 월드 공간 위치
    DirectX::XMFLOAT3 position;
    // Billboard Quad의 크기
    float size;
    // Billboard Quad의 색상
    DirectX::XMFLOAT4 color;
};
```

기존 코드에서는 **단일 Billboard만 렌더링**하여 Billboard Quad의 월드 공간 위치, 크기, 색상 정보를 `billboardRenderer` 클래스의 멤버로 설정해 사용하였습니다.

여러 Billboard를 렌더링하기 위해서는 **각 Billboard에 대한 정보가 독립적으로 구성**되어야 하므로, 이를 위한 **구조체 `Billboard`를 추가**하였습니다. (기존에 사용하던 멤버 변수는 제거)

```C
class BillboardRenderer
{
public:
    ...
	
private:
    ...
	
    // Billboard 중심점에 적용할 월드 변환 행렬을 생성하는 함수
    DirectX::XMMATRIX BuildBillboardWorldMatrix
    (
	    const DirectX::XMFLOAT3& position
	) const;
	
    // 현재 프레임에서 사용할 Billboard 변환 행렬을 갱신하는 함수
    void UpdateTransformBuffer
    (
	    ID3D11DeviceContext* context,
	    const Camera& camera,
	    const DirectX::XMFLOAT3& position
	);
	
    // 현재 카메라 기준으로 Billboard를 펼치기 위한 정보를 갱신하는 함수
    void UpdateBillboardInfoBuffer
    (
	    ID3D11DeviceContext* context,
	    const Camera& camera,
	    const Billboard& billboard
	);
	
private:
	...
	
    // 렌더링할 Billboard Quad의 리스트
    std::vector<Billboard> m_billboards;
};
```

기존 멤버 변수(`m_position`, `m_size`, `m_color`)를 내부적으로 사용하던 함수들에 대한 **함수 시그니처를 수정**하였습니다.


**billboard_renderer.cpp**

```C
DirectX::XMMATRIX BillboardRenderer::BuildBillboardWorldMatrix
(
	const DirectX::XMFLOAT3& position
) const
{
    // Billboard 중심 위치를 월드 공간으로 옮기는 이동 행렬 생성
    return DirectX::XMMatrixTranslation
    (
        position.x,
        position.y,
        position.z
    );
}
```

기존 `BuildBillboardWorldMatrix` 함수는 내부적으로 `m_position` 멤버 변수를 사용하였으므로, **`XMFLOAT3` 형식의 파라미터를 입력**받아 사용하도록 구조를 변경하였습니다.


```C
void BillboardRenderer::UpdateTransformBuffer
(
	ID3D11DeviceContext* context,
	const Camera& camera,
	const DirectX::XMFLOAT3& position
)
{
    ...
	
    // Billboard 중심 위치에 적용할 월드 변환 행렬
    const DirectX::XMMATRIX world = BuildBillboardWorldMatrix(position);
	
    ...
}
```

`UpdateTransformBuffer` 함수는 내부적으로 `BuildBillboardWorldMatrix` 함수를 호출하는 구조이므로, **`XMFLOAT3` 형식의 파라미터를 입력**받아 사용하도록 구조를 변경하였습니다.

```C
void BillboardRenderer::UpdateBillboardInfoBuffer
(
	ID3D11DeviceContext* context,
	const Camera& camera,
	const Billboard& billboard
)
{
    ...
    
    // Billboard 정보 버퍼 데이터 설정
    BillboardInfoBufferData billboardInfoData = {};
    ...
    billboardInfoData.billboardSize = billboard.size;
    ...
    billboardInfoData.billboardColor = billboard.color;
	
    ...
}
```

기존 `UpdateBillboardInfoBuffer` 함수는 내부적으로 `m_size`, `m_color` 멤버 변수를 사용하는 구조였으므로, **`Billboard` 구조체를 파라미터로 입력**받은 뒤 해당 구조체의 멤버를 추출하여 사용하도록 수정하였습니다.

```C
void BillboardRenderer::Render
(
	ID3D11DeviceContext* context,
	const Camera& camera,
	const std::vector<Billboard>& billboards
)
{
    ...
	
    // Billboard 데이터 목록을 순회하며 각각의 위치, 크기, 색상으로 렌더링
    for (const Billboard& billboard : billboards)
    {
        // 현재 Billboard의 위치를 기준으로 변환 버퍼 갱신
        UpdateTransformBuffer(context, camera, billboard.position);
		
        // 현재 Billboard의 크기, 색상, 카메라 기준 축 정보 갱신
        UpdateBillboardInfoBuffer(context, camera, billboard);
		
        // 현재 Billboard Quad 렌더링
        context->DrawIndexed
        (
            m_indexCount,
            0,
            0
        );
    }
}
```

`Render` 함수에서 **파라미터로 입력받은 Billboard 리스트를 순회**하여 각 Billboard를 렌더링하도록 수정하였습니다.

기존의 Billboard 구성 정보(`billboardWorldPosition`, `billboardSize`, `billboardColor`)를 제거하고, **렌더링할 Billboard Quad 리스트(`m_billboards`)를 구성**하였습니다.

```C
void App::Render()
{
    ...
	
    // Billboard Quads 렌더링

	(
		m_renderer.GetContext(),
		m_camera,

	);
	
	...

```

구성한 리스트를 `BillboardRenderer` 객체의 `Render` 함수의 파라미터로 전달하여 **Billboard Quads를 렌더링**하였습니다.
