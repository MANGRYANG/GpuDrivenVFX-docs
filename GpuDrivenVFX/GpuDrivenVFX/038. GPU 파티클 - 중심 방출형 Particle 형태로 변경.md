# 주요 내용

## 💻 코드

**particle/gpu_particle_system.h**

```C
// GPU 기반 Particle 시뮬레이션에서 사용할 Particle 데이터 구조체
struct GpuParticleData
{
    ...
    
    // Particle이 생성된 뒤 경과한 시간
    float age = 0.0f;
    // 현재 Particle이 활성 상태인지 여부
    std::uint32_t active = 0;
    // 중심 회전형 Particle의 현재 반지름
    float orbitRadius = 0.0f;
    // 중심 회전형 Particle의 현재 각도
    float orbitAngle = 0.0f;
	
    // 중심 회전형 Particle의 각속도
    float angularVelocity = 0.0f;
    // 중심에서 바깥쪽으로 퍼지는 속도
    float radialVelocity = 0.0f;
    // GPU 구조체 정렬을 맞추기 위한 패딩
    DirectX::XMFLOAT2 padding = DirectX::XMFLOAT2(0.0f, 0.0f);
};
```

파티클 데이터를 담는 구조체 `GpuParticleData`에 **중심 방출형 파티클 정보를 추가**하였습니다.

```C
class GpuParticleSystem

    // GPU Particle을 지속적으로 생성하기 위한 Emitter 설정 구조체
    struct ParticleEmitter
    {
        ...
        
        // Spiral Arm 배치를 계산하기 위한 GPU Particle 생성 순서

        ...
    };

```

GPU 파티클 시스템의 Emitter 구조체(`ParticleEmitter`)에 **Spiral Arm 배치 계산을 위한 파티클 생성 순서 멤버**를 추가하였습니다. (`spawnSequence`) 

```C
class GpuParticleSystem
{
private:
    ...
    
    // 중심 방출형 파티클 평면에 대한 회전 행렬을 계산하는 함수
    void CalculateSpiralBasis();
    
    // 중심 방출형 파티클 평면의 로컬 X축을 월드 방향으로 변환한 기저
    DirectX::XMFLOAT4 m_spiralRight;
    // 중심 방출형 파티클 평면의 로컬 Y축을 월드 방향으로 변환한 기저
    DirectX::XMFLOAT4 m_spiralUp;
    // 중심 방출형 파티클 평면의 로컬 Z축을 월드 방향으로 변환한 기저
    DirectX::XMFLOAT4 m_spiralForward;
};
```

**중심 방출형 파티클 평면에 대한 회전 행렬을 계산하는 함수**를 선언하였습니다.
(`CalculateSpiralBasis`)

해당 함수에서 계산된 회전 행렬은 **각 행이 추출되어 멤버 변수로 저장**됩니다.

`spiralRight` - 회전 행렬의 첫 번째 행 (회전 후 기저의 X축 방향)
`spiralUp` - 회전 행렬의 두 번째 행 (회전 후 기저의 Y축 방향)
`spiralForward` - 회전 행렬의 세 번째 행 (회전 후 기저의 Z축 방향)

파티클 상태 갱신을 위한 구조체(`ParticleUpdateBufferData`)에 **파티클 위치 계산을 위한 중심 방출형 파티클 정보를 추가로 전달**하였습니다.

추가로 **파티클 평면에 적용할 회전 행렬**의 각 행을 전달하였습니다.

`Initialize` 단계에서 `CalculateSpiralBasis` 함수를 호출하여 **회전 행렬을 계산**하였습니다.

```C
void GpuParticleSystem::Update(ID3D11DeviceContext* context, float deltaTime)
{
    ...
	
    // 이번 프레임에 생성할 GPU Particle 개수 계산
    const std::uint32_t spawnCount = ConsumeSpawnCount(deltaTime);
	
    // 이번 프레임의 GPU Particle 생성 시작 슬롯 인덱스 기록
    const std::uint32_t spawnStartIndex = m_emitter.spawnIndex;
	
    // 이번 프레임의 GPU Particle 생성 시작 순서 기록
    const std::uint32_t spawnSequenceStart = m_emitter.spawnSequence;
	
    // 다음 프레임의 GPU Particle 생성 시작 슬롯 인덱스와 생성 순서 갱신
    if (spawnCount > 0)
    {
        m_emitter.spawnIndex = ...;
		
        m_emitter.spawnSequence += spawnCount;
    }

    // GPU Particle 업데이트 상수 버퍼 갱신
    UpdateParticleUpdateBuffer
    (
	    context,
	    deltaTime,
	    spawnStartIndex,
	    spawnCount,
	    spawnSequenceStart
	);
	
	...
}
```

`Update` 함수에서 `UpdateParticleUpdateBuffer` 함수를 호출할 때, **이번 프레임에서 생성되는 첫 파티클의 생성 인덱스**(`spawnSequenceStart`)를 계산하여 전달하도록 수정하였습니다.

해당 인자는 `UpdateParticleUpdateBuffer` 함수에서 **파티클 갱신 버퍼 데이터로 구성**되어, **파티클의 Spiral Arm 배치를 결정하는 데 활용**됩니다.

```C
void GpuParticleSystem::UpdateParticleUpdateBuffer
(
    ...
    std::uint32_t spawnSequenceStart
)
{
    ...
	
    // GPU Particle 업데이트 상수 버퍼 데이터 구성
    ParticleUpdateBufferData bufferData = {};
    bufferData.emitterPosition = m_emitter.position;
    bufferData.particleSize = m_emitter.particleSize;
    bufferData.emitterVelocity = m_emitter.velocity;
    bufferData.particleLifetime = m_emitter.particleLifetime;
    bufferData.emitterColor = m_emitter.color;
    bufferData.deltaTime = deltaTime;
    bufferData.particleCount =
	    static_cast<std::uint32_t>(ParticleConfig::ParticleCapacity);
    bufferData.spawnStartIndex = spawnStartIndex;
    bufferData.spawnCount = spawnCount;
    bufferData.spawnSequenceStart = spawnSequenceStart;
    bufferData.spiralArmCount = ParticleConfig::SpiralArmCount;
    bufferData.orbitStartRadius = ParticleConfig::OrbitStartRadius;
    bufferData.orbitAngularVelocity = ParticleConfig::OrbitAngularVelocity;
    bufferData.orbitRadialVelocity = ParticleConfig::OrbitRadialVelocity;
    bufferData.spiralPitch = ParticleConfig::SpiralPitch;
    bufferData.spiralYaw = ParticleConfig::SpiralYaw;
    bufferData.spiralDepthScale = ParticleConfig::SpiralDepthScale;
    bufferData.spiralDepthFrequency = ParticleConfig::SpiralDepthFrequency;
    bufferData.padding = DirectX::XMFLOAT3(0.0f, 0.0f, 0.0f);
	
    ...
}
```

`UpdateParticleUpdateBuffer` 함수에서 생성하는 버퍼가 **중심 방출형 파티클의 상태 갱신을 위한 정보를 가지도록 수정**하였습니다.

해당 과정에서 `particle/particle_config.h` 파일에서 설정한 공통 값들을 사용하였습니다.


**shader/GpuParticleUpdateComputeShader.hlsl**

```HLSL
// 2 PI 근사
static const float TwoPi = 6.28318530718f;

// Spiral Arm을 균등 분배하기 위한 계산기
float CalculateSpiralArmBaseAngle(uint armIndex)
{
    return (float) armIndex * (TwoPi / (float) spiralArmCount);
}
```

**입력된 Spiral Arm에 대한 각도를 계산**하는 `CalculateSpiralArmBaseAngle` 함수를 추가하였습니다.

```HLSL
// 중심 방출형 파티클 평면에 대한 회전을 적용하기 위한 함수
float3 RotateSpiralPosition(float3 localPosition)
{
    return
	    (localPosition.x * spiralRight.xyz)
	    + (localPosition.y * spiralUp.xyz)
	    + (localPosition.z * spiralForward.xyz);
}
```

`ParticleUpdateBuffer`를 통해 전달된 회전 행렬의 각 행을 사용하여, **인자로 주어진 위치 벡터에 회전을 적용**하는 함수를 구현하였습니다.

```HLSL
// 중심 방출형 Spiral Particle의 로컬 위치 계산
float3 CalculateSpiralLocalPosition
(
	float orbitAngle,
	float orbitRadius,
	float age
)
{
    float localX = cos(orbitAngle) * orbitRadius;
    float localY = sin(orbitAngle) * orbitRadius;
	
    float zOffset =
        sin(orbitAngle * spiralDepthFrequency + age * spiralDepthFrequency)
        * (orbitRadius * spiralDepthScale);
	
    return RotateSpiralPosition(float3(localX, localY, zOffset));
}
```

 **파티클의 각도 및 반지름, 나이를 기반으로 중심 방출형 파티클의 로컬 공간 위치를 계산**하는 함수를 추가하였습니다.

입체감을 부여하기 위해 사인 파동 함수를 적용하였습니다.

```HLSL
[numthreads(64, 1, 1)]
void CS_Main(uint3 dispatchThreadId : SV_DispatchThreadID)
{
    ...
	
    // 활성 Particle의 수명 및 위치 갱신
    if (particle.active != 0)
    {
        // Particle 생존 시간 누적
        particle.age += deltaTime;
		
        // 수명이 끝난 Particle은 비활성화
        if (particle.age >= particle.lifetime)
        {
            particle.active = 0;
        }
        else
        {
            // 수명 비율에 따라 바깥쪽 Particle의 회전 속도를 점진적으로 감속
            float speedFactor = 1.0f - particle.age / particle.lifetime;
            
            // 중심 회전형 Particle의 각도와 반지름 갱신
            particle.orbitAngle +=
	            (particle.angularVelocity * speedFactor) * deltaTime;
            particle.orbitRadius += particle.radialVelocity * deltaTime;
            
            // 중심점을 기준으로 회전 좌표를 계산하여 Particle 위치 갱신
            float3 rotatedPosition = 
	            CalculateSpiralLocalPosition
	            (
		            particle.orbitAngle,
		            particle.orbitRadius,
		            particle.age
		        );
			
            particle.position = emitterPosition + rotatedPosition;
        }
		
        // 갱신된 Particle 데이터를 GPU Buffer에 다시 기록
        particles[particleIndex] = particle;
    }
    ...
}
```

현재 프레임에서 활성 상태인 파티클에 대한 **각도 및 반지름**을 `deltaTime` 기반으로 갱신하고, 해당 정보를 `CalculateSpiralLocalPosition` 함수에 전달하여 **현재 파티클의 로컬 공간 위치를 계산**합니다.

```HLSL
[numthreads(64, 1, 1)]
void CS_Main(uint3 dispatchThreadId : SV_DispatchThreadID)
{
    ...
    
    bool shouldSpawn = false;
    uint spawnOffset = 0;
	
    // Ring Buffer 방식으로 spawnStartIndex부터
    // spawnCount개 슬롯에 새 Particle 생성
    uint spawnEndIndex = spawnStartIndex + spawnCount;

    if (spawnCount > 0)
    {
        // 배열 끝을 넘지 않는 경우
        if (spawnEndIndex <= particleCount)
        {
            shouldSpawn =
	            (particleIndex >= spawnStartIndex) &&
	            (particleIndex < spawnEndIndex);
			
            if (shouldSpawn)
            {
                spawnOffset = particleIndex - spawnStartIndex;
            }
        }

        // 배열 끝을 넘어서 맨 앞으로 돌아가는 경우
        else
        {
            uint wrappedEndIndex = spawnEndIndex % particleCount;
			
            if (particleIndex >= spawnStartIndex)
            {
                shouldSpawn = true;
                spawnOffset = particleIndex - spawnStartIndex;
            }
            else if (particleIndex < wrappedEndIndex)
            {
                shouldSpawn = true;
                spawnOffset =
	                (particleCount - spawnStartIndex)
	                + particleIndex;
            }
        }
    }

    // Spawn 대상 슬롯이면 새 Particle 데이터로 덮어쓰기
    if (shouldSpawn)
    {
        uint spawnSequence = spawnSequenceStart + spawnOffset;
        uint armIndex = spawnSequence % spiralArmCount;
		
        float orbitAngle = CalculateSpiralArmBaseAngle(armIndex);
		
        particle.orbitRadius = orbitStartRadius;
        particle.orbitAngle = orbitAngle;
        particle.angularVelocity = orbitAngularVelocity;
        particle.radialVelocity = orbitRadialVelocity;
		
        particle.position = emitterPosition +
            float3
            (
                cos(particle.orbitAngle) * particle.orbitRadius,
                sin(particle.orbitAngle) * particle.orbitRadius,
                0.0f
            );
		
        particle.size = particleSize;
        particle.velocity = emitterVelocity;
        ...
    }
    ...
}
```

새 파티클을 생성할 때 해당 파티클에 대한 `spawnOffset`을 계산한 뒤, 이를 바탕으로 `armIndex`를 특정하여 파티클이 **해당 Spiral Arm에 배치될 수 있도록 구현**하였습니다.
