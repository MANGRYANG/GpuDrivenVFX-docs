# 주요 내용

## 💻 코드

**app.cpp**

```C
void App::Render()
{
    // 프레임 드로우 준비 및 배경 색 초기화 (#0D141F)
    m_renderer.BeginFrame(0.05f, 0.08f, 0.12f, 1.0f);
	
    // Billboard Quads 렌더링
    m_billboardRenderer.Render
    (
	    m_renderer.GetContext(),
	    m_camera,
	    m_cpuParticleSystem.GetBillboards()
	);
	
    // 최종 화면 출력
    m_renderer.EndFrame();
}
```

Quad 메쉬를 렌더링하는 코드를 비활성화하여 **중앙에 렌더링되던 Quad를 제거**하였습니다.

기존에는 화면 중앙에 Quad가 렌더링되어 **Particle 테스트에 방해**가 되는 문제가 있었습니다.

![[Screenshot-016-01.png]]

코드 비활성화 후, Quad 메쉬가 더 이상 렌더링되지 않아 **Particle 관측 테스트의 편의성이 향상**되었습니다.
