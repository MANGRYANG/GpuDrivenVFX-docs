# 일일 목표

- [x] CPU/GPU 파티클 시스템에서 각자 사용하던 MaxParticleCount를 공통으로 관리

***
# 주요 내용

## 🏭 리팩토링

**particle/particle_config.h**

```C
#pragma once

#include <cstddef>

namespace ParticleConfig
{
    // CPU, GPU Particle System에서 사용할 최대 Particle 슬롯 개수
    constexpr std::size_t ParticleCapacity = 64;
}
```

MaxParticleCount를 공통으로 관리하기 위한 Config 헤더를 추가하였습니다.

해당 config 헤더를 각 파티클 시스템에서 인클루드하고, 기존에 관리하던 `MaxParticleCount`를 `ParticleConfig::ParticleCapacity`로 치환하였습니다.

이를 통해 CPU/GPU 파티클 시스템에서 각자 관리하던 **최대 파티클 슬롯 개수 상수**를 하나의 config 파일을 통해 공통적으로 관리할 수 있게 되었습니다.
