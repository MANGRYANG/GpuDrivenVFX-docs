# 주요 내용

## 💻 코드

**particle/cpu_particle_system.cpp**

```C
void CpuParticleSystem::Initialize()
{
    ...
	
    // 초기 테스트 Particle 목록 생성
    m_particles =
    {
        {
            ...
            3.0f,
            0.0f,
            ...
        },
        {
            ...
            5.0f,
            0.0f,
            ...
        },
        {
            ...
            7.0f,
            0.0f,
            ...
        }
    };

    // 초기 Particle 데이터를 렌더링용 Billboard 목록으로 변환
    RebuildBillboards();
}
```

`Initialize` 단계에서 생성하는 Particle 목록의 `lifetime` 수치를 조정하였습니다.
(모든 Particle의 `age` 수치는 0으로 고정하였습니다.)

- **첫 번째 Particle (노란색)**: `lifetime` 수치를 3으로 설정하였습니다. → **생명 주기 3초**
- **두 번째 Particle (하늘색)**: `lifetime` 수치를 5으로 설정하였습니다. → **생명 주기 5초**
- **세 번째 Particle (주황색)**: `lifetime` 수치를 7으로 설정하였습니다. → **생명 주기 7초**

```C
void CpuParticleSystem::Update(float deltaTime)
{
    // 활성 Particle의 수명 및 위치 갱신
    for (Particle& particle : m_particles)
    {
        if (!particle.active)
        {
            continue;
        }
		
        // 활성 Particle의 생존 시간 누적
        particle.age += deltaTime;
        
        // 수명이 끝난 Particle은 비활성화
        if (particle.age >= particle.lifetime)
        {
            particle.active = false;
            continue;
        }
		
        // 활성 Particle의 위치를 속도와 deltaTime 기반으로 갱신
        particle.position.x += particle.velocity.x * deltaTime;
        particle.position.y += particle.velocity.y * deltaTime;
        particle.position.z += particle.velocity.z * deltaTime;
    }
	
    // 현재 Particle 상태를 렌더링용 Billboard 목록으로 변환
    RebuildBillboards();
}
```

`Update` 단계에서 활성 상태인 Particle의 **누적 생존 시간(`age`)을 갱신**하고, **누적 생존 시간이 수명(`lifetime`) 이상의 수치로 갱신된 경우 해당 Particle을 비활성화**하도록 구현하였습니다.
