# 주요 내용

## 💻 코드

**particle/gpu_particle_system.h**

```C
class GpuParticleSystem
{
private:
    // GPU Particle 업데이트 상수 버퍼를 갱신하는 함수
    void UpdateParticleUpdateBuffer
    (
        ID3D11DeviceContext* context,
        float deltaTime,
        std::uint32_t spawnStartIndex,
        std::uint32_t spawnCount
    );
    
    // 이번 프레임에 생성할 GPU Particle 개수를 계산하는 함수
	std::uint32_t ConsumeSpawnCount(float deltaTime);
	
private:
    // GPU Particle을 지속적으로 생성하기 위한 Emitter 설정 구조체
    struct ParticleEmitter
    {
        // GPU Particle이 생성될 월드 공간 위치
        DirectX::XMFLOAT3 position = DirectX::XMFLOAT3(0.45f, -0.5f, 0.0f);
        // GPU Particle의 초기 이동 속도
        DirectX::XMFLOAT3 velocity = DirectX::XMFLOAT3(0.0f, 0.35f, 0.0f);
        // GPU Particle을 Billboard로 렌더링할 때 사용할 크기
        float particleSize = 0.01f;
        // GPU Particle의 총 생존 시간
        float particleLifetime = 3.0f;
        // 초당 생성해야 하는 GPU Particle 개수
        float spawnRate = 8.0f;
        // 프레임마다 누적되는 생성 요청 수
        float spawnAccumulator = 0.0f;
        // 다음 프레임에 GPU Particle을 생성할 순환 슬롯 인덱스
        std::uint32_t spawnIndex = 0;
        // GPU Particle을 Billboard로 렌더링할 때 사용할 색상
        DirectX::XMFLOAT4 color = DirectX::XMFLOAT4(0.5f, 0.5f, 1.0f, 1.0f);
    };
	
    // GPU Particle Emitter
    ParticleEmitter m_emitter;
};
```

GPU Particle을 지속적으로 생성하기 위한 Emitter 구조체 `ParticleEmitter`를 구성하였습니다.

`GpuParticleSystem`에 **Emitter 객체를 멤버로 추가**하고, `UpdateParticleUpdateBuffer` 함수의 인자로 현재 프레임의 `spawnStartIndex`와 `spawnCount`를 추가로 전달하도록 수정하였습니다.

- `spawnStartIndex`: 이번 프레임에 새로 생성할 Particle 정보를 쓰기 시작할 슬롯 인덱스
- `spawnCount`: 이번 프레임에 새로 생성할 Particle의 개수

`UpdateParticleUpdateBuffer` 함수에 전달할 `spawnCount`를 계산하기 위한 함수도 추가하였습니다. (`ConsumeSpawnCount`)


**particle/gpu_particle_system.cpp**

```C
void GpuParticleSystem::Update(ID3D11DeviceContext* context, float deltaTime)
{
    ...
	
    // 이번 프레임에 생성할 GPU Particle 개수 계산
    const std::uint32_t spawnCount = ConsumeSpawnCount(deltaTime);
	
    // 이번 프레임의 GPU Particle 생성 시작 슬롯 인덱스 기록
    const std::uint32_t spawnStartIndex = m_emitter.spawnIndex;
	
    // 다음 프레임의 GPU Particle 생성 시작 슬롯 인덱스 갱신
    if (spawnCount > 0)
    {
        m_emitter.spawnIndex =
	        static_cast<std::uint32_t>
		        ((m_emitter.spawnIndex + spawnCount) % MaxParticleCount);
    }
	
    // GPU Particle 업데이트 상수 버퍼 갱신
    UpdateParticleUpdateBuffer
	(
		context,
		deltaTime,
		spawnStartIndex,
		spawnCount
	);
	
    ...
}
```

`Update` 함수에서 **이번 프레임에 생성할 Particle 개수**(`spawnCount`)와 **이번 프레임에서 생성할 Particle 정보를 기록할 슬롯 인덱스**(`spawnStartIndex`)를 계산하고, `spawnStartIndex`를 갱신하여 다음 프레임에서 사용할 수 있도록 설정하였습니다.

```C
void GpuParticleSystem::UpdateParticleUpdateBuffer
(
    ID3D11DeviceContext* context,
    float deltaTime,
    std::uint32_t spawnStartIndex,
    std::uint32_t spawnCount
)
{
    ...
	
    // GPU Particle 업데이트 상수 버퍼 데이터 구성
    ParticleUpdateBufferData bufferData = {};
    bufferData.emitterPosition = m_emitter.position;
    bufferData.particleSize = m_emitter.particleSize;
    bufferData.emitterVelocity = m_emitter.velocity;
    bufferData.particleLifetime = m_emitter.particleLifetime;
    bufferData.emitterColor = m_emitter.color;
    bufferData.deltaTime = deltaTime;
    bufferData.particleCount = static_cast<std::uint32_t>(MaxParticleCount);
    bufferData.spawnStartIndex = spawnStartIndex;
    bufferData.spawnCount = spawnCount;
	
    // CPU 메모리의 상수 버퍼 데이터를 GPU 상수 버퍼에 업데이트
    context->UpdateSubresource
    (
        m_particleUpdateBuffer.Get(),
        0,
        nullptr,
        &bufferData,
        0,
        0
    );
	
    // Compute Shader 단계에 상수 버퍼 바인딩
    ID3D11Buffer* constantBuffers[] =
    {
        m_particleUpdateBuffer.Get()
    };
	
    context->CSSetConstantBuffers
    (
        0,
        1,
        constantBuffers
    );
}
```

`UpdateParticleUpdateBuffer` 함수에서는 **Emitter 속성값과 생성 제어값(`spawnStartIndex`, `spawnCount`)도 추가로 전달되도록 수정**하였습니다.

_`ParticleUpdateBufferData` 구조체는 Emitter 속성값 및 생성 제어값을 통합하여 16바이트 정렬을 준수하도록 확장하였습니다._

```C
std::uint32_t GpuParticleSystem::ConsumeSpawnCount(float deltaTime)
{
    // 생성 요청 수 누적
    m_emitter.spawnAccumulator += m_emitter.spawnRate * deltaTime;
	
    // 이번 프레임에 생성할 수 있는 Particle 개수 계산
    const std::uint32_t spawnCount =
	    static_cast<std::uint32_t>( );
	
    // 생성할 Particle이 없는 경우
    if (spawnCount == 0)
    {
        return 0;
    }
	
    // 처리한 생성 요청 수만큼 누적값 감소
    m_emitter.spawnAccumulator -= static_cast<float>(spawnCount);
	
    // 한 프레임에서 최대 Particle 수를 초과해 생성하지 않도록 제한
    if (spawnCount > MaxParticleCount)
    {
        return static_cast<std::uint32_t>(MaxParticleCount);
    }
	
    return spawnCount;
}
```

`ConsumeSpawnCount` 함수에서는 1초에 `spawnRate` 만큼의 Particle을 생성하기 위하여 현재 프레임에 `spawnRate * deltaTime` 만큼의 **생성 요청을 누적**하고, **이번 프레임에서 처리할 생성 요청 수만큼 누적 값을 감소**시킵니다.

반환된 **현재 프레임에서 처리될 생성 요청의 개수**는 `UpdateParticleUpdateBuffer` 함수의 인자로 전달되어, **GPU 내에서 수행되는 파티클 Spawn 작업에 활용**됩니다.


**shaders/GpuParticleUpdateComputeShader.hlsl**

```HLSL
// GPU Particle 업데이트 상수 버퍼
cbuffer ParticleUpdateBuffer : register(b0)
{
    float3 emitterPosition;
    float particleSize;
	
    float3 emitterVelocity;
    float particleLifetime;
	
    float4 emitterColor;
	
    float deltaTime;
    uint particleCount;
    uint spawnStartIndex;
    uint spawnCount;
};
```

**GpuParticleSystem의 `UpdateParticleUpdateBuffer`에서 수정한 상수 버퍼의 형식에 맞게 Compute Shader의 상수 버퍼 데이터 레이아웃을 구성**하였습니다.

```HLSL
// 하나의 thread group에서 64개의 Particle 슬롯을 처리
[numthreads(64, 1, 1)]
void CS_Main(uint3 dispatchThreadId : SV_DispatchThreadID)
{
    // 현재 thread가 담당할 Particle 인덱스
    uint particleIndex = dispatchThreadId.x;
	
    // Particle 범위를 벗어난 thread는 처리하지 않음
    if (particleIndex >= particleCount)
    {
        return;
    }
	
    // 현재 Particle 데이터 읽기
    GpuParticleData particle = particles[particleIndex];
	
    // 활성 Particle의 수명 및 위치 갱신
    if (particle.active != 0)
    {
        // Particle 생존 시간 누적
        particle.age += deltaTime;
		
        // 수명이 끝난 Particle은 비활성화
        if (particle.age >= particle.lifetime)
        {
            particle.active = 0;
        }
        else
        {
            // Particle 위치를 속도와 deltaTime 기반으로 갱신
            particle.position += particle.velocity * deltaTime;
        }
		
        // 갱신된 Particle 데이터를 GPU Buffer에 다시 기록
        particles[particleIndex] = particle;
    }
    
    // 이번 프레임에 Spawn할 Particle 슬롯인지 확인
    bool shouldSpawn = false;
	
    // Ring Buffer 방식
    // spawnStartIndex부터 spawnCount개 슬롯에 새 Particle 생성
    for (uint spawnOffset = 0; spawnOffset < spawnCount; ++spawnOffset)
    {
        uint targetIndex = (spawnStartIndex + spawnOffset) % particleCount;
		
        if (particleIndex == targetIndex)
        {
            shouldSpawn = true;
            break;
        }
    }
	
    if (!shouldSpawn)
    {
        return;
    }
	
    // 슬롯 인덱스를 사용해 수평 퍼짐 부여
    float spread = (float) (particleIndex % 5);
	
    GpuParticleData spawnedParticle;
    spawnedParticle.position =
	    emitterPosition + float3(spread * 0.03f, 0.0f, 0.0f);
    spawnedParticle.size = particleSize;
    spawnedParticle.velocity =
	    emitterVelocity + float3(spread * 0.03f, 0.0f, 0.0f);
    spawnedParticle.lifetime = particleLifetime;
    spawnedParticle.color = emitterColor;
    spawnedParticle.age = 0.0f;
    spawnedParticle.active = 1;
    spawnedParticle.padding = float2(0.0f, 0.0f);
	
    // 새 Particle 데이터를 GPU Buffer에 기록
    particles[particleIndex] = spawnedParticle;
}
```

Compute Shader가 **생존 파티클의 상태 갱신**과 **신규 파티클의 생성(Spawn)** 로직을 하나의 파이프라인으로 통합하여 처리하도록 수정하였습니다.

기존에 구현되었던 생존 상태 파티클에 대한 상태 갱신을 마무리한 후, **상수 버퍼를 통해 전달받은 `spawnStartIndex`와 `spawnCount`를 기반으로 Ring Buffer의 특정 슬롯 범위를 계산**합니다.

해당 범위 내에 위치한 스레드는 기존 데이터를 무시하고 `Emitter` 설정값에 따라 새로운 파티클 데이터를 덮어쓰는 방식으로 파티클을 Spawn하도록 구현하였습니다.

_시각적 연출을 위한 수평 퍼짐( `Spread` ) 현상을 부여하였습니다_
