# 주요 내용

## 💻 코드

**app.h**

```C
// Quad의 위치, 회전, 스케일 정보를 기반으로 월드 변환 행렬을 생성하는 함수
DirectX::XMMATRIX BuildQuadWorldMatrix() const;

...

// 월드 좌표계에서의 Quad 위치 정보
DirectX::XMFLOAT3 m_quadPosition = DirectX::XMFLOAT3(0.0f, 0.0f, 0.0f);
// 월드 좌표계에서의 Quad 회전 정보
DirectX::XMFLOAT3 m_quadRotation = DirectX::XMFLOAT3(0.0f, 0.0f, 0.0f);
// 월드 좌표계에서의 Quad 크기 배율
float m_quadScale = 1.0f;
```

**Quad의 위치, 회전, 크기 값을 App 클래스의 멤버로 명시**하였으며, 해당 정보를 기반으로 월드 변환 행렬을 생성하는 함수 `BuildQuadWorldMatrix`를 선언하였습니다.

**app.cpp**

```C
DirectX::XMMATRIX App::BuildQuadWorldMatrix() const
{
    // 스케일 행렬 생성
    const DirectX::XMMATRIX scale = DirectX::XMMatrixScaling
    (
        m_quadScale,
        m_quadScale,
        m_quadScale
    );
	
    // 회전 행렬 생성
    const DirectX::XMMATRIX rotation = DirectX::XMMatrixRotationRollPitchYaw
    (
        m_quadRotation.x,
        m_quadRotation.y,
        m_quadRotation.z
    );
	
    // 이동 행렬 생성
    const DirectX::XMMATRIX translation = DirectX::XMMatrixTranslation
    (
        m_quadPosition.x,
        m_quadPosition.y,
        m_quadPosition.z
    );
	
    // 변환 행렬 계산 (SRT)
    return scale * rotation * translation;
}
```

`BuildQuadWorldMatrix` 함수 내부에서 스케일 행렬, 회전 행렬, 이동 행렬을 생성한 뒤, 행렬곱을 통해 **월드 변환 행렬을 계산하고 반환**하도록 작성하였습니다.

Quad의 이동 및 회전 정보를 (0, 0, 0)으로 설정하고, 스케일 정보를 1로 설정하였으므로 실행 결과 **기존과 변화 없는 사각형이 출력**되었습니다.
