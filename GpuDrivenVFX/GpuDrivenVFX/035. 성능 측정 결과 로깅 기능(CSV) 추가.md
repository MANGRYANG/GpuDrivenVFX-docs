{

CSV 로깅을 위한 파일 스트림을 `App`의 멤버 변수로 추가하였습니다.

`App::Initialize`에서 `InitializeParticlePerformanceCsvLog` 함수를 호출하여 **CSV 파일을 초기화**하고, `App::PrintParticlePerformanceInfo`에서 `WriteParticlePerformanceCsvRow` 함수를 호출하여 **CSV 파일에 로깅 작업을 수행**합니다.


**core/app.cpp**

```C
void App::InitializeParticlePerformanceCsvLog()
{
    // 기존 CSV 로그 파일을 덮어쓰기 방식으로 생성
    m_particlePerformanceCsvFile.open
    (
        "particle_performance.csv",
        std::ios::out | std::ios::trunc
    );
	
    // CSV 파일을 열지 못한 경우 성능 로그 파일 출력만 비활성화
    if (!m_particlePerformanceCsvFile.is_open())
    {
        OutputDebugStringW
        (
	        L"[Perf] Failed to open particle_performance.csv\n"
	    );
        return;
    }
	
    // CSV Header 작성
    m_particlePerformanceCsvFile
        << "mode,"
        << "particle_capacity,"
        << "update_ms,"
        << "render_ms,"
        << "frame_ms,"
        << "fps\n";
	
    // Header가 바로 파일에 기록되도록 flush
    m_particlePerformanceCsvFile.flush();
}
```

이전 로그와 뒤섞이지 않도록 `std::ios::out | std::ios::trunc` 설정을 통해 **프로그램을 실행할 때마다 `particle_performance.csv` 파일이 새로 생성되도록 설정**하였습니다.

**설정된 CSV 헤더는 아래와 같습니다.**

`mode` - 로그 출력 당시의 파티클 시스템 모드 (CPU / GPU)
`particle_capacity` - 해당 모드에서 생성 가능한 최대 파티클 수
`update_ms` - 1초 간 수행된 프레임에서의 Update 작업에 소요된 평균 시간(ms)
`render_ms` - 1초 간 수행된 프레임에서의 Render 작업에 소요된 평균 시간(ms)
`frame_ms` - 1초 간 수행된 프레임에서의 전체 작업에 소요된 평균 시간(ms)
`fps` - Frame per Second (1초 당 수행된 프레임 수)

```C
void App::WriteParticlePerformanceCsvRow
(
    double averageUpdateMilliseconds,
    double averageRenderMilliseconds,
    double averageFrameMilliseconds,
    double fps
)
{
    // CSV 파일이 열려 있지 않은 경우 기록하지 않음
    if (!m_particlePerformanceCsvFile.is_open())
    {
        return;
    }
	
    // 소수점 자릿수 고정
    m_particlePerformanceCsvFile << std::fixed << std::setprecision(6);
	
    switch (m_particleSimulationMode)
    {
    case ParticleSimulationMode::CPU:
        m_particlePerformanceCsvFile
            << "CPU,"
            << m_cpuParticleSystem.GetMaxParticleCount() << ","
            << averageUpdateMilliseconds << ","
            << averageRenderMilliseconds << ","
            << averageFrameMilliseconds << ","
            << fps
            << "\n";
        break;
		
    case ParticleSimulationMode::GPU:
        m_particlePerformanceCsvFile
            << "GPU,"
            << m_gpuParticleSystem.GetMaxParticleCount() << ","
            << averageUpdateMilliseconds << ","
            << averageRenderMilliseconds << ","
            << averageFrameMilliseconds << ","
            << fps
            << "\n";
        break;
    }
	
    // 측정 중 프로그램이 종료되어도 기록 손실을 줄이기 위해 매 row마다 flush
    m_particlePerformanceCsvFile.flush();
}
```

`WriteParticlePerformanceCsvRow` 함수에서는 **각 성능 측정 지표들을 소수점 아래 6자리까지 CSV 파일(`particle_performance.csv`)에 로깅하는 작업을 수행**합니다.

각 행마다 `flush()`를 호출하여 프로그램이 예상치 못하게 종료되어도 기록이 손실되지 않도록 작성하였습니다.
