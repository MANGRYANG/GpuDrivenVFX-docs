## 💻 코드

**rendering/billboard.h**

```C
#pragma once

#include <DirectXMath.h>

// Billboard Quad 정보 구조체
struct Billboard
{
    // Billboard Quad의 월드 공간 위치
    DirectX::XMFLOAT3 position;
    // Billboard Quad의 크기
    float size;
    // Billboard Quad의 색상
    DirectX::XMFLOAT4 color;
};
```

기존 `rendering/billboard_renderer.h` 파일에 정의하였던 **Billboard 정보 구조체(`Billboard`)를 새 헤더 파일로 생성**하였습니다.

 **CPU Particle System, GPU Particle System에서 사용할 Billboard Renderer**를 개별적으로 분리하고, 두 렌더러 모두 해당 구조체를 사용하도록 구현할 예정입니다.

**CPU Particle System에서 사용할 Billboard Renderer**를 표현하는 클래스를 선언하였습니다.

해당 클래스는 CPU Particle System으로부터 전달받은 Billboard 목록을 **인스턴스 버퍼 기반으로 렌더링**합니다.

클래스에서 선언된 **주요 멤버 함수**는 다음과 같습니다.

- `Initialize`
  렌더링 루프 진입 전에 **GPU 리소스를 준비하고 상태를 설정**하는 초기화 함수입니다.
  
	- `CreateQuadBuffers`
	  **정점 버퍼 및 인덱스 버퍼를 생성**합니다.
	- `CreateInputLayout`
	  **CPU와 GPU 간 입력 레이아웃을 생성**합니다.
	  인스턴싱을 위해 `D3D11_INPUT_PER_INSTANCE_DATA` 속성으로 정의하였습니다.
	- `CreateCameraBuffer`
	 **카메라의 뷰/투영 변환 행렬을 전달하기 위한 상수 버퍼를 생성**합니다.
  
- `Render`
  매 프레임 호출되어 **최신 데이터를 GPU로 전송하고, 그리기 명령을 수행**하는 함수입니다.
  `DrawIndexedInstanced`를 통해 **1번의 Draw Call로 여러 인스턴스를 병렬 처리**합니다.

	- `UpdateInstanceBuffer`
		**현재 프레임에서 사용할 인스턴스 데이터를 인스턴스 버퍼에 업로드**합니다.
			- `EnsureInstanceBuffer`
			  현재 Billboard 개수를 담을 수 있는 크기의 인스턴스 버퍼를 확보합니다.
	- `UpdateCameraBuffer`
	  **현재 프레임에서 사용할 카메라 변환 행렬을 정점 셰이더에 전달**합니다.

(
	ID3D11DeviceContext* context,
	const Camera& camera
)
{
    ...
	
    // 카메라 버퍼 데이터 설정
    CameraBufferData cameraData = {};
    ...
	
    // CPU 메모리의 카메라 버퍼 데이터를 GPU의 카메라 버퍼에 업데이트

        0,
        nullptr,
        &cameraData,
        0,
        0
    );
	
    // 파이프라인 입력 슬롯에 전달할 상수 버퍼 포인터 배열

    {
        m_cameraBuffer.Get()
    };
	
    // 정점 셰이더 단계의 상수 버퍼 설정
    context->VSSetConstantBuffers
    (
        0,
        1,
        constantBuffers
    );
}

매 프레임마다 `Render` 함수에서 `UpdateCameraBuffer` 함수를 내부적으로 호출하며, **카메라의 뷰 변환 및 투영 변환에 사용되는 변환 행렬을 상수 버퍼 형태로 정점 셰이더에 전달**하도록 설정하였습니다.


**shader/CpuBillboardVertexShader.hlsl**

```HLSL
// CPU Billboard 렌더링에 사용할 카메라 변환 버퍼를 0번 슬롯에 바인딩
cbuffer CameraBuffer : register(b0)
{
    matrix view;
    matrix projection;
};

// CPU Billboard Vertex Buffer와 Instance Buffer로부터 입력받는 데이터 구조체
struct VSInput
{
    // Billboard 중심점을 기준으로 Quad의 각 정점이 펼쳐질 방향 (X, Y)
    float2 Corner : TEXCOORD0;
	
    // Billboard 인스턴스의 월드 공간 중심 위치
    float3 InstancePosition : POSITION;
    // Billboard 인스턴스의 크기
    float InstanceSize : TEXCOORD1;
    // Billboard 인스턴스의 색상
    float4 InstanceColor : COLOR;
};

// Vertex Shader 연산 후 래스터라이저로 넘길 데이터 구조체
struct VSOutput
{
    // 4차원 동차 좌표계 위치 (X, Y, Z, W)
    float4 Pos : SV_POSITION;
    // Pixel Shader로 전달할 색상 데이터 (R, G, B, A)
    float4 Color : COLOR;
};

// 각 CPU Billboard 정점마다 실행되는 정점 셰이더의 Entry Point
VSOutput VS_Main(VSInput input)
{
    VSOutput output;
	
    // Billboard 중심점을 월드 공간에서 뷰 공간으로 변환
    float4 centerView = mul(float4(input.InstancePosition, 1.0f), view);
	
    // 뷰 공간의 XY 평면에서 Quad를 확장해 카메라를 향하는 Billboard를 구성
    float4 positionView = centerView;
    positionView.xy += input.Corner.xy * input.InstanceSize;
	
    // 뷰 공간 위치를 투영 좌표계로 변환
    output.Pos = mul(positionView, projection);
	
    // 인스턴스 색상을 Pixel Shader로 전달
    output.Color = input.InstanceColor;
	
    return output;
}
```

`UpdateCameraBuffer` 함수를 통해 매 프레임마다 전달받은 **카메라 버퍼를 읽어, 카메라 변환 행렬을 통해 Billboard의 중심점 위치 및 방향을 계산**합니다.
