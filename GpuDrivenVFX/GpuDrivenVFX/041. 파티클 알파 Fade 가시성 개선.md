# 주요 내용

## 💻 코드

**particle/particle_config.h**

```C
namespace ParticleConfig
{
    ...
    
    // Particle 수명 중 fade-out이 시작되는 비율
    constexpr float ParticleFadeOutStartRatio = 0.0f;
}
```

파티클 생성 직후부터 페이드 아웃이 수행되도록 `ParticleFadeOutStartRatio` 값을 0으로 설정하였습니다.


**particle/cpu_particle_system.cpp**

```C
namespace
{
    ...
	
    // 투명도 적용을 위한 계산기
    float CalculateFadeOutAlpha(float normalizedAge)
    {
        ...
		
        // 최종 알파 값 계산
        const float alpha = 1.0f - fadeProgress;
		
        ...
		
        // Alpha 값의 제곱을 반환
        return alpha * alpha;
    }
}
```

CPU 파티클 시스템에서 **파티클 페이드 아웃 효과의 가시성을 개선**하기 위해, 계산한 알파 값의 제곱을 적용하도록 수정하였습니다.


**shaders/GpuParticleUpdateComputeShader.hlsl**

```HLSL
// fade-out 효과를 위한 알파 값 계산 함수
float CalculateFadeOutAlpha(float normalizedAge)
{
    ...
	
    // 최종 알파 값 계산 (0-1 구간으로 클램핑)
    float alpha = saturate(1.0f - fadeProgress);
    
    // Alpha 값의 제곱 반환
    return alpha * alpha;
}

```

GPU 파티클 시스템에서도 동일한 방식으로 **파티클 페이드 아웃 효과의 가시성을 개선**하였습니다.
