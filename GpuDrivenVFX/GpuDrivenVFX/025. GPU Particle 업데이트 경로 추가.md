# 일일 목표

- [x] Compute Shader를 통한 GPU Particle 업데이트 경로 추가

***
# 주요 내용

## 💻 코드

**particle/gpu_particle_system.h‎**

```C
class GpuParticleSystem
{
public:
    // GPU Compute Shader를 사용해 Particle 데이터를 갱신하는 함수
    void Update(ID3D11DeviceContext* context, float deltaTime);
	
	// GPU Particle 업데이트용 Compute Shader를 생성하는 함수
    bool CreateComputeShader(ID3D11Device* device);
	
    // GPU Particle 업데이트에 사용할 상수 버퍼를 생성하는 함수
    bool CreateParticleUpdateBuffer(ID3D11Device* device);
	
    // GPU Particle 업데이트 상수 버퍼를 갱신하는 함수
    void UpdateParticleUpdateBuffer
    (
	    ID3D11DeviceContext* context,
	    float deltaTime
	);
    
private:
    // GPU Particle 업데이트에 사용할 Constant Buffer
    Microsoft::WRL::ComPtr<ID3D11Buffer> m_particleUpdateBuffer;
    
    ...
    
    // GPU Particle 업데이트를 수행할 Compute Shader
    Microsoft::WRL::ComPtr<ID3D11ComputeShader> m_computeShader;
}
```

**Compute Shader 기반의 Particle 상태 갱신**을 위한 멤버 함수 및 멤벼 변수를 추가하였습니다.

`m_particleUpdateBuffer`은 `deltaTime`이나 외부 물리 환경 변수처럼 **매 프레임마다 Compute Shader에 전달해야 할 정보를 관리**하는 상수 버퍼입니다.

`CreateComputeShader` 함수를 통해 Particle 업데이트를 위한 **Compute Shader를 로드**하고, `CreateParticleUpdateBuffer` 함수를 통해 Particle 업데이트를 위한 **상수 버퍼를 생성**합니다.

매 프레임마다 `UpdateParticleUpdateBuffer` 함수를 호출하여 `m_particleUpdateBuffer`를 갱신하고, 최종적으로 `Update` 함수 내에서 Compute Shader를 파이프라인에 바인딩한 뒤 `Dispatch`를 호출하여 **GPU 기반의 병렬 파티클 시뮬레이션을 수행**합니다.

```C
namespace
{
    // GPU Particle 업데이트 상수 버퍼 데이터 구조체
    struct ParticleUpdateBufferData
    {
        float deltaTime;
        std::uint32_t particleCount;
        DirectX::XMFLOAT2 padding;
    };
	
    // GPU Particle 업데이트 상수 버퍼는 16바이트 정렬을 만족해야 함
    static_assert
    (
	    sizeof(ParticleUpdateBufferData) == 16,
	    "ParticleUpdateBufferData size must be 16 bytes."
	);
}
```

`m_particleUpdateBuffer`이 Compute Shader에 `deltaTime`, `particleCount`를 매 프레임마다 전달하도록 구조체를 정의하였습니다. (`ParticleUpdateBufferData`)

`ParticleUpdateBufferData`는 상수 버퍼로 사용되므로, **16바이트 정렬을 검사하는 코드를 삽입**하여 CPU와 GPU 간 데이터 동기화 안정성을 확보하였습니다.


**particle/gpu_particle_system.cpp**

```C
void GpuParticleSystem::Update(ID3D11DeviceContext* context, float deltaTime)
{
    ...
	
    // GPU Particle 업데이트 상수 버퍼 갱신
    UpdateParticleUpdateBuffer(context, deltaTime);
	
    // Compute Shader 바인딩
    context->CSSetShader(m_computeShader.Get(), nullptr, 0);
	
    // Particle UAV를 Compute Shader에 바인딩
    ID3D11UnorderedAccessView* unorderedAccessViews[] =
    {
        m_particleUav.Get()
    };
	
    context->CSSetUnorderedAccessViews
    (
        0,
        1,
        unorderedAccessViews,
        nullptr
    );
	
    // 64개 thread를 하나의 group으로 사용
    static constexpr UINT ThreadGroupSize = 64;
	
    // 전체 Particle 개수를 처리할 thread group 수 계산
    const UINT threadGroupCount = static_cast<UINT>
        ((MaxParticleCount + ThreadGroupSize - 1) / ThreadGroupSize);
	
    // GPU Compute Shader Dispatch
    context->Dispatch(threadGroupCount, 1, 1);
	
    // 이후 렌더링 단계에서 동일 버퍼를 SRV로 사용할 수 있도록 UAV 바인딩 해제
    ID3D11UnorderedAccessView* nullUnorderedAccessViews[] = { nullptr };
	
    context->CSSetUnorderedAccessViews
    (
        0,
        1,
        nullUnorderedAccessViews,
        nullptr
    );
	
    // Compute Shader 상수 버퍼 바인딩 해제
    ID3D11Buffer* nullConstantBuffers[] = { nullptr };
    
    context->CSSetConstantBuffers
    (
        0,
        1,
        nullConstantBuffers
    );
	
    // Compute Shader 바인딩 해제
    context->CSSetShader(nullptr, nullptr, 0);
}
```

`Update` 함수의 작동 방식은 다음과 같습니다.

- Particle 업데이트를 위한 **상수 버퍼를 생성**하고, **Compute Shader를 바인딩**한 후 파티클 데이터를 GPU가 직접 수정할 수 있도록 **UAV(Unordered Access View)를 바인딩**합니다.
  
- 전체 파티클 개수를 처리하기 위한 **스레드 그룹** 개수를 계산하고, `context->Dispatch` 함수의 인자로 전달하여 **GPU 코어들이 파티클 데이터를 병렬로 갱신하도록 명령**합니다.
  
- 연산이 완료되면 **이후 렌더링 단계에서 Particle Buffer를 SRV로 사용할 수 있도록 UAV 바인딩을 해제**하고, **상수 버퍼 및 셰이더 바인딩을 순차적으로 해제**합니다.


**GpuParticleComputeShader.hlsl**

```HLSL
struct GpuParticleData
{
    float3 position;
    float size;
	
    float3 velocity;
    float lifetime;
	
    float4 color;
	
    float age;
    uint active;
    float2 padding;
};

// Compute Shader에서 읽고 쓸 GPU Particle Buffer
RWStructuredBuffer<GpuParticleData> particles : register(u0);
```

Compute Shader가 GPU Particle Buffer의 원소를 올바르게 해석할 수 있도록 **`GpuParticleData` 데이터 레이아웃을 정의**하였습니다.
Compute Shader는 **UAV로 바인딩된 GPU Particle Buffer**를 `RWStructuredBuffer<GpuParticleData>` 형태로 읽고 쓸 수 있습니다. (UAV 슬롯 0번에 바인딩)

```HLSL
// GPU Particle 업데이트 상수 버퍼
cbuffer ParticleUpdateBuffer : register(b0)
{
    float deltaTime;
    uint particleCount;
    float2 padding;
};
```

GpuParticleSystem의 `UpdateParticleUpdateBuffer`에서 바인딩한 **상수 버퍼**를 `register(b0)` 슬롯을 통해 Compute Shader에 전달하여 파티클 시뮬레이션의 물리 연산에 활용하도록 설정하였습니다.

```HLSL
// 하나의 thread group에서 64개의 Particle 슬롯을 처리
[numthreads(64, 1, 1)]
void CS_Main(uint3 dispatchThreadId : SV_DispatchThreadID)
{
    // 현재 thread가 담당할 Particle 인덱스
    uint particleIndex = dispatchThreadId.x;
	
    // Particle 범위를 벗어난 thread는 처리하지 않음
    if (particleIndex >= particleCount)
    {
        return;
    }
	
    // 현재 Particle 데이터 읽기
    GpuParticleData particle = particles[particleIndex];
	
    // 비활성 Particle은 갱신하지 않음
    if (particle.active == 0)
    {
        return;
    }
	
    // Particle 생존 시간 누적
    particle.age += deltaTime;
	
    // 수명이 끝난 Particle은 비활성화
    if (particle.age >= particle.lifetime)
    {
        particle.active = 0;
        particles[particleIndex] = particle;
        return;
    }
	
    // Particle 위치를 속도와 deltaTime 기반으로 갱신
    particle.position += particle.velocity * deltaTime;
	
    // 갱신된 Particle 데이터를 GPU Buffer에 다시 기록
    particles[particleIndex] = particle;
}
```

`[numthreads(64, 1, 1)]`을 통해 **64개의 스레드가 하나의 그룹을 형성하여 파티클의 상태를 병렬로 갱신**하도록 설정하였습니다.

먼저 `SV_DispatchThreadID`를 통해 **현재 스레드가 처리할 파티클을 식별**하고, `particles` 버퍼로부터 데이터를 읽어와 활성 상태를 확인합니다.
이후 활성 상태인 파티클의 생존 시간(`age`)를 누적하고 수명이 다한 파티클은 비활성화 처리하여 **현재 프레임에서의 파티클 생존 상태를 확인**하였습니다.

현재 프레임에서 생존한 파티클은 **위치 및 속도를 `deltaTime` 기반으로 갱신**하고, **갱신된 데이터를 GPU VRAM의`particles` 버퍼에 다시 기록**하여 렌더링 단계에서 최신 상태가 반영될 수 있도록 설계하였습니다.
