# 일일 목표

- [x] Mesh를 그리는 데 필요한 정점 데이터의 소유권을 App으로 이관

***
# 주요 내용

## 🏭 리팩토링

기존 코드에서는 **정점 데이터의 생성과 소유권이 모두 `Mesh` 클래스에 종속**되어 있었으며, 이로 인해 새로운 형태의 도형을 그리게 되면 내부 코드를 직접 수정하거나 별도의 클래스를 구현해야 하는 구조적 한계를 가지고 있었습니다.

이를 해결하기 위해 **정점 데이터의 생성 및 소유권을 애플리케이션(`App`)으로 이관하고, 메쉬 초기화 함수의 파라미터로 `std::vector<Vertex>` 형태의 구조체 배열을 전달받는 방식**으로 구조를 변경하였습니다.

 **app.cpp**
 
 ```C
// 삼각형을 구성할 정점 데이터를 담은 배열
const std::vector<Vertex> triangleVertices =
{
    {
        DirectX::XMFLOAT3(0.0f, 0.5f, 0.0f),
        DirectX::XMFLOAT3(0.0f, 0.0f, -1.0f),
        DirectX::XMFLOAT4(1.0f, 0.0f, 0.0f, 1.0f)
    },
    {
        DirectX::XMFLOAT3(0.4f, -0.5f, 0.0f),
        DirectX::XMFLOAT3(0.0f, 0.0f, -1.0f),
        DirectX::XMFLOAT4(0.0f, 1.0f, 0.0f, 1.0f)
    },
    {
        DirectX::XMFLOAT3(-0.4f, -0.5f, 0.0f),
        DirectX::XMFLOAT3(0.0f, 0.0f, -1.0f),
        DirectX::XMFLOAT4(0.0f, 0.3f, 1.0f, 1.0f)
    }
}
 ```

- 삼각형을 그리는 데 필요한 정점 데이터를 `app.cpp`에서 생성하도록 변경
- 정점 데이터를 담는 데이터 구조를 C 스타일 배열에서 **가변 배열**로 변경


**mesh.h**

```C
bool Initialize
(
	ID3D11Device* device,
	ID3DBlob* vertexShaderBlob,
	const std::vector<Vertex>& vertices
);
```

- **함수명 변경** (`InitializeTriangle` → `Initialize`)
- Mesh 초기화 함수의 파라미터로 **정점 구조체 배열을 전달**하도록 수정
