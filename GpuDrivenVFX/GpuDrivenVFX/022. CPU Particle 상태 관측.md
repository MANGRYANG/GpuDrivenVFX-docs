**particle/cpu_particle_system.cpp**

```C
std::size_t CpuParticleSystem::GetRenderParticleCount() const
{
    return m_billboards.size();
}
```

현재 렌더링되고 있는 Particle 개수를 반환하는 `GetRenderParticleCount` 함수는 내부적인 카운터 없이, **BillboardRenderer에 전달할 렌더링용 Billboard 목록의 크기를 반환**하도록 설정하였습니다.

```C
bool CpuParticleSystem::SpawnParticle(...)
{
    // 비활성 Particle 슬롯을 검색
    for (Particle& particle : m_particles)
    {
        // 활성 Particle인 경우 무시
        if (particle.active)
        {
            continue;
        }
		
        ...
		
        return true;
    }
	
    // 사용 가능한 비활성 Particle 슬롯이 없는 경우
    ++m_droppedSpawnCount;
    return false;
}
```

Particle을 생성하는 `SpawnParticle` 함수에서 **사용 가능한 비활성 상태의 Particle 슬롯이 없어 생성에 실패한 경우** `m_droppedSpawnCount` 값을 1 증가시키도록 설정하였습니다.

**app.cpp**

```C
void App::PrintParticleDebugInfo(float deltaTime)
{
    // Particle 상태 디버그 출력 누적 시간 갱신
    m_particleDebugPrintAccumulator += deltaTime;
	
    // 1초마다 Particle 상태를 Output 창에 출력
    if (m_particleDebugPrintAccumulator >= 1.0f)
    {
        // 다음 출력 주기를 위해 누적 시간 감소
        m_particleDebugPrintAccumulator -= 1.0f;
		
        // Particle 상태 출력 문자열 구성
        wchar_t debugText[128] = {};
        swprintf_s
        (
            debugText,
            128,
            L"[Particle] render=%zu / max=%zu, dropped=%zu\n",
            m_cpuParticleSystem.GetRenderParticleCount(),
            m_cpuParticleSystem.GetMaxParticleCount(),
            m_cpuParticleSystem.GetDroppedSpawnCount()
        );
		
        // Output 창에 Particle 상태 출력
        OutputDebugStringW(debugText);
    }
}
```

**매 프레임마다 호출되는 디버그 메시지 출력 함수**를 구현하였습니다.

누적 시간 변수를 갱신하고, 해당 시간이 인터벌 값(`1.0f`)보다 커지면 `OutputDebugStringW` 함수를 통해 **Visual Studio Output 창에 디버그 메시지를 출력**하도록 작성하였습니다.

이 과정에서, 디버그 메시지를 구성하기 위해 기존에 구현하였던 Particle 상태 조회 API를 사용하였습니다.

```C
void App::Update()
{
    // 현재 프레임의 deltaTime 갱신
    m_frameTimer.Tick();
	
    // 현재 프레임에서 사용할 deltaTime 값 조회
    const float deltaTime = m_frameTimer.GetDeltaTime();
	
    // 실제 deltaTime 값으로 CPU Particle System 업데이트
    m_cpuParticleSystem.Update(deltaTime);
	
    // 현재 프레임의 Particle 상태 디버그 메시지 출력
    PrintParticleDebugInfo(deltaTime);
    
}
```

App의 `Update` 단계에서 `PrintParticleDebugInfo` 함수를 호출하여 **1초마다 Particle 상태 디버그 메시지를 출력**하도록 하였습니다.

실행 결과, Particle 상태 디버그 메시지가 잘 출력되는 것을 확인하였습니다.
