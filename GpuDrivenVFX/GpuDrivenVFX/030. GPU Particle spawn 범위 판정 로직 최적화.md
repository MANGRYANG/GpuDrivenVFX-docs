# 주요 내용

## 🏭 리팩토링

**shaders/GpuParticleUpdateComputeShader.hlsl**

```HLSL
// 이번 프레임에 Spawn할 Particle 슬롯인지 확인
bool shouldSpawn = false;

// Ring Buffer 방식으로 spawnStartIndex부터 spawnCount개 슬롯에 새 Particle 생성
uint spawnEndIndex = spawnStartIndex + spawnCount;

if (spawnCount > 0)
{
	// 배열 끝을 넘지 않는 경우
	if (spawnEndIndex <= particleCount)
	{
		shouldSpawn =
			(particleIndex >= spawnStartIndex) &&
			(particleIndex < spawnEndIndex);
	}
	
	// 배열 끝을 넘어서 맨 앞으로 돌아가는 경우
	else
	{
		uint wrappedEndIndex = spawnEndIndex % particleCount;
		
		shouldSpawn =
			(particleIndex >= spawnStartIndex) ||
			(particleIndex < wrappedEndIndex);
	}
}
```

Particle 상태 업데이트용 Compute Shader의 **spawn 대상 Particle 판정을 루프 기반에서 범위 검사 방식으로 변경**하였습니다.

Particle별 spawn 판정에 대한 비용이 다음과 같이 최적화되었습니다.

	`O(spawnCount)` → `O(1)`
